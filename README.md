# skills-copilot-codespaces-vscode

Learn Copilot to write a university essay.

## Working topic

**NIS2 Transposition as a Policy Shock: Analyzing the Increase in Cybersecurity Procurement and Spending**  
Target length: **75-85 pages**

## Efficient working environment (first setup)

### 1) Clear objectives

- Produce a complete research manuscript (75-85 pages) with citations and appendices.
- Build a reproducible workflow for evidence collection, outline, drafting, and revision.
- Track assumptions, data limits, and policy interpretations transparently.

### 2) Rules

- Every claim must be linked to a verifiable source (law text, policy paper, procurement data, official report).
- Separate facts, interpretation, and hypotheses in notes and drafts.
- Use versioned milestones: outline -> chapter drafts -> integrated draft -> final revision.
- Keep writing focused on the causal question: **did NIS2 transposition increase cybersecurity procurement/spending?**

### 3) Core variables to track

- **Independent variable**: NIS2 transposition timing/intensity by country.
- **Dependent variables**: cybersecurity procurement volume, contract value, and spending trends.
- **Controls**: country size, baseline digital maturity, prior cybersecurity regulation, major cyber incidents.
- **Outputs**: chapter progress, source quality score, evidence gaps, open questions.

### 4) Suggested agent-assisted workflow (optional)

- Use an agent for repetitive tasks (source extraction, table formatting, bibliography cleanup).
- Keep decision checkpoints manual (research framing, variable definitions, causal interpretation).
- Define one prompt template per task type (search, summarize, critique, draft).

## First test to start working

Run a **7-day pilot sprint** before full drafting:

1. Build a 2-page research brief (question, scope, causal mechanism, expected contribution).
2. Create a seed bibliography of at least 20 high-quality sources.
3. Draft a preliminary chapter outline with estimated page allocation to reach 75-85 pages.
4. Prepare a variable sheet (definitions, data source, expected direction, caveats).
5. Write one 1,000-1,500 word mini-section testing the argument structure.
6. End-of-sprint review: what worked, what blocked progress, what to change in the environment.
